e-plantShopping

Paradise Nursery - Online Plant Shop

This repository, e-plantShopping, contains the front end of Paradise Nursery, an online houseplant store built with React and Redux Toolkit as the final project for the IBM Full Stack Software Developer course.

Features:
- Landing page with a background image, company introduction and a Get Started button
- Product listing page with houseplants grouped into categories, each showing a thumbnail, name and price
- Add to Cart button that disables once a plant is in the cart
- Header with navigation and a cart icon that shows the number of items in the cart
- Shopping cart page with item thumbnails, unit prices, quantity increase and decrease buttons, delete buttons, cart totals, Continue Shopping and Checkout

Tech stack: React, Redux Toolkit, Vite, deployed with GitHub Pages.
